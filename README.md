# 📡 Signal 10

> **Tune the signal. Discover the news that matters to you.**

**Signal 10** is a Flask-based web application designed to provide a different way of discovering news.

Instead of simply displaying a conventional news feed, Signal 10 uses a **1–10 rating meter** to let users indicate the kind of news they want to explore.

The lower the selected number, the more the experience leans toward **entertainment and lighter news**.

As the number increases, the application moves toward **more serious, important, and critical news**.
